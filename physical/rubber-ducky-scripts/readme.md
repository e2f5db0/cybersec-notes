ducky scripts
=============

1. Run jsencoder
```bash
firefox jsencoder.html
```

2. Download the keyboard layout JSON file from [here](https://github.com/hak5/bashbunny-payloads/tree/master/languages).

3. Write the script or insert from ```DuckyScript_InProgress.txt``` text file.

4. Generate Payload & copy ```inject.bin``` to the root of the rubber ducky.
